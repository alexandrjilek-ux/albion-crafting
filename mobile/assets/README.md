# Assets — placeholders

Tyto PNG soubory jsou **placeholdery vygenerované při scaffoldingu** (single-color
indigo canvas s violet glow blobem uprostřed). Nahraď je finálními assety před
prvním App Store submitem:

| Soubor                | Rozměr     | Účel                                   |
|-----------------------|-----------:|----------------------------------------|
| `icon.png`            | 1024×1024  | Master app icon (Expo to derivuje)     |
| `splash.png`          | 1242×2436  | Splash screen (iPhone X+ baseline)     |
| `adaptive-icon.png`   | 1024×1024  | Android adaptive icon foreground       |
| `favicon.png`         |  48×48     | Web favicon (pokud build pro web)      |

App Store Connect chce 1024×1024 RGBA bez průhlednosti pro App Icon. Doporučení
pro Frost & Arcane brand crest: stylizované "A" s violet → deep mage gradientem,
indigo pozadí, jemný frost cyan accent (např. tečka nad "A" jako "i").
